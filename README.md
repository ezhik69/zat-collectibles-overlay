# ZAT Collectibles Overlay

Внешний оверлей для **Zombie Army Trilogy**, который показывает оставшиеся коллекционные предметы на текущей карте.

## Скачать

Готовая версия для Windows x64 находится в разделе [Releases](../../releases). Скачайте ZIP, распакуйте его в любую папку и запустите `ZAT Collectibles.exe`. Устанавливать .NET отдельно не требуется.

## Как запустить

1. Запустите Zombie Army Trilogy и загрузите сюжетную карту.
2. Включите оконный режим или режим без рамки.
3. Запустите `ZAT Collectibles.exe`.
4. Вернитесь в игру. Оверлей появится, когда окно игры станет активным.

Жёлтая рамка показывает золотой слиток, красная — бутылку крови. Рядом отображается расстояние от камеры. Язык интерфейса меняется кнопкой `English / Русский` и сохраняется между запусками.

## Совместимость

Текущая версия проверена с `ZAT.exe`, имеющим SHA-256:

```text
4794f61f96356906a1775a95aa9f00482a42c2dd029fb3cdfb4b541cd1ba903a
```

Программа подключается к уже запущенному `ZAT.exe` и только читает память процесса. Она не внедряет DLL, не изменяет память игры и сохранения.

Другие версии `ZAT.exe` могут быть несовместимы. Кооперативный режим пока отдельно не проверен.
